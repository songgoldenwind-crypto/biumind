# 任务工作台用户指南

任务是 BiuMind 的主入口：创建任务、看执行、收可验收产物。产品层叫「任务」，存储仍是一条会话线程。手机是遥控台，真正改文件的是家里开着 BiuMind 的电脑，或云端 Runtime 池。

端到端成功标准：手机下一句「把这份纪要整理成周报」→ 绑定的在线电脑开跑（或你明确改成云端任务）→ 写文件前手机能批准 → 完成后结果区能打开产物（本机路径或可下载文件）→ 关掉手机，电脑/云端继续；再打开仍是同一任务。

## 认识界面

桌面是三栏：左侧任务列表、中间任务对话、右侧约 300px 结果区。窄屏（手机）是两级页面——底栏第一项「任务」先看列表，点进任务后全屏对话，左上角返回列表；结果区从详情 AppBar 打开约 72% 高的半屏。

电脑要开着桌面 BiuMind（`biu serve` / daemon），手机才能把 agent 任务派到那台机器。没有在线电脑时不会偷偷改成纯问答。

### 任务列表

列表顶部芯片：全部 / 执行中 / 等你 / 已完成 / 失败。状态优先级是「等你 > 执行中 > 失败 > 已完成 > 排队」。本机正在跑或正在等你时，列表芯片以实时状态为准；杀 App 或换设备后，芯片回退到服务端记下的上一状态。

未选中任务时，右侧（或手机空列表）是欢迎页：问候、起点卡、一句话入口。空列表分两种：还没有任何任务走欢迎；芯片或搜索把结果滤空则提示没有匹配的任务。

文案必须出现「电脑要开着 BiuMind」。手机首页底部可一句话下发；展开「选项」可选先计划或改用云端任务。没有在线电脑时 SnackBar 也会给出「改用云端任务」。点 `+` 打开完整新建对话框。

## 开始一个任务

### 三种执行落点

| 模式 | 说明 |
|---|---|
| Agent | 工具在你选定的在线电脑上执行（`biu_daemon` / `biu_cli`）。必须选中电脑才能创建。 |
| 云端任务 | 不绑电脑，调度到 Runtime 池。没有空闲 runtime 时会提示暂不可用。 |
| 问答 | 纯模型问答，不落文件。导航不再把它当主路径宣传。 |

无在线电脑还选 Agent：提示「没有在线电脑。打开桌面 BiuMind，或改用云端任务。」**不会插入空任务**。一句话下发同样先探活电脑，没有则 SnackBar，不建任务。

开跑时电脑已被回收：横幅 +「改用云端任务」。改完变成云端任务且 `runtimeEnvMode=cloud`，**不会自动重发**，避免在错误落点跑起来。

### 先计划 / 直接执行

新建对话框（Agent / 云端任务）以及手机一句话下的折叠行可选：

| 选项 | 行为 |
|---|---|
| 直接执行（默认） | 沿用你的批准档位（出厂「手动批准」）。Agent 拿到需求就动手，写文件仍受放权约束。 |
| 先计划 | 强制手动批准，并在系统提示前加上：「先给出分步计划，等用户确认后再改文件。」第一轮允许问答，写文件仍走审批卡。 |

### 工作目录

Agent 需要一个授权文件夹。桌面在新建对话框或输入框底部的工作目录 chip 里选择；选中后会记住，下次手机一句话建 Agent 任务会带上这个目录。手机选不了电脑磁盘，所以不会弹出系统目录选择器。

仍为空时允许创建并发送，但 composer 会显示「未授权文件夹」。第一次写文件的审批卡必须让你看清路径。要改目录：进任务详情，用桌面 chip，或改用云端任务。

### 发送与停止

- **Enter** 发送，**Shift+Enter** 换行；手机软键盘上回车是换行，发送走输入框右下角按钮。
- 生成过程中变成停止按钮。停止后消息尾部会标注「已停止」。
- 点进任务会自动接上同一条 Agent Plane 会话（续跑）。列表页不预连 WebSocket，审批必须进详情。

## 选择模型

模型是**任务级**设置。点击输入框底部的模型 chip 弹出选择对话框：按提供方分组，显示价格与上下文窗口；平台默认模型带「默认」徽标。

快捷键 Cmd/Ctrl+Shift+M 直接唤出。

费用预估、积分不足、模型不可用的横幅与一键修复（重选模型 / 升级会员）与原来相同。

## 结果区与产物

桌面右侧默认打开结果区；手机详情 AppBar「结果」打开同一套内容。四个页签：产物、全部文件、变更、预览。

Agent 写下文件后，结果区从消息里抽出路径，并合并服务端记下的 `file_id`。

打开规则：

- 有可下载的文件 id → 换临时链接，系统分享/下载。
- 仅本地路径，且当前设备就是那台电脑 → 用系统打开。
- 手机只有路径、没有文件 id → 显示「文件在电脑：{path}」。上传失败时任务仍算已完成，结果区保留电脑路径并提示未同步到云端。

办公二进制（pptx / xlsx / pdf）本阶段只显示路径和摘要，不做真预览。CSV / Markdown 可看文本摘录。

## 与智能体协作：审批与表单

遥控默认**手动批准**：写文件前手机必须能看到审批卡。审批通道是 Agent Plane WebSocket，不是列表页上的 REST。列表「等你」只是提醒你点进任务；点进后 resume，重放未应答的请求，再在 composer 上方的审批卡里允许或拒绝。

| 按钮 | 效果 |
|---|---|
| 允许 | 放行本次调用 |
| 始终允许 | 放行本次，并把本任务批准档位升为「自动批准」 |
| 拒绝 | 跳过本次调用 |

助手需要你拍板时会浮出表单卡（单选 / 多选 / 自由文本）。超时未答会标注；暂停的会话仍可再答。

桌面可信目录可以把批准档改成白名单或全自动。

## 管理任务

悬停、右键或手机长按列表条目：置顶、重命名、归档、导出 JSON、删除。手机可左滑快速归档。归档页可解归档或永久删除。

收藏、跨任务搜索、会话内搜索、导入导出、命令面板（Cmd/Ctrl+K）仍然可用。斜杠命令、@ 技能、联网搜索、图片附件与原来相同。

## 键盘快捷键

按 **Shift+?**（输入框未聚焦时）可查看快捷键面板。

| 快捷键 | 作用 |
|---|---|
| Enter | 发送 |
| Shift+Enter | 换行 |
| ↑ / ↓ | 翻阅输入历史 |
| `/` | 斜杠命令菜单 |
| Cmd/Ctrl+K | 命令面板 |
| Cmd/Ctrl+N | 新建任务 |
| Cmd/Ctrl+P | 置顶 / 取消置顶当前任务 |
| Cmd/Ctrl+Shift+F | 搜索全部任务 |
| Cmd/Ctrl+F | 在当前任务中搜索 |
| Cmd/Ctrl+Shift+M | 切换模型 |
| F2 | 重命名当前任务 |
| Cmd/Ctrl+E | 归档当前任务 |
| Cmd/Ctrl+Shift+E | 导出当前任务 JSON |
| Cmd/Ctrl+Backspace | 删除当前任务 |
| Shift+? | 快捷键面板 |

macOS 上修饰键为 ⌘，Windows / Linux 上为 Ctrl；手机端不显示快捷键提示。技能的安装与管理参见 [Skills 用户指南](skills.md)。
